# Biblioteca de Videojuegos

## ¿Qué hará la aplicación?

La aplicación será una biblioteca de videojuegos que permitirá almacenar y consultar información sobre diferentes videojuegos. Mostrará los datos de cada videojuego y permitirá comprobar cuáles están disponibles en la biblioteca.

Actualmente, la aplicación contiene datos de ejemplo y los muestra mediante `console.table()` en la consola del navegador.

## Campos de los videojuegos

Cada videojuego tiene los siguientes campos:

* **id**: identificador único del videojuego.
* **titulo**: nombre del videojuego.
* **genero**: género al que pertenece.
* **plataforma**: plataforma en la que se puede jugar.
* **anio**: año de lanzamiento.
* **disponible**: indica si el videojuego está disponible en la biblioteca.

## ¿Cómo se ejecuta?

1. Clonar o descargar el proyecto.
2. Abrir la carpeta del proyecto con Visual Studio Code.
3. Abrir el archivo `index.html` en un navegador.
4. Abrir las herramientas de desarrollador del navegador pulsando **F12**.
5. Entrar en la pestaña **Console**.
6. Comprobar que aparece la tabla con los videojuegos mediante `console.table()` y que no hay errores en rojo.
